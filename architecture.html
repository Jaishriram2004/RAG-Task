Component Details

rag_main.py

Orchestrates the entire data pipeline from Google Drive sync to embedding storage

Python Google Drive API

rag_agent.py

Core RAG engine handling query processing and response generation

LangChain FAISS Ollama

embeddings_manager.py

Manages vector embeddings and FAISS index operations

Sentence Transformers FAISS

text_processor.py

Extracts text from PDF, DOCX, and TXT files

PyMuPDF python-docx

sentence_chunker.py

Intelligently chunks text by sentences for optimal embedding

NLTK 500 char chunks

rag_chat_ui.py

Gradio-based chat interface for user interaction

Gradio Real-time
